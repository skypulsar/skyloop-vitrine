FAQ

Les questions qu'on nous pose souvent.

Un site vitrine simple est livré en 2 à 3 semaines après validation du cadrage. Un site e-commerce ou une application sur mesure prend 4 à 8 semaines selon le périmètre. Vous avez le calendrier détaillé dans le devis.
À vous, à 100%. Le code source intégral est livré dans un repository Git que vous possédez. Aucune licence, aucun verrou propriétaire — vous pouvez en faire ce que vous voulez, y compris le confier à un autre prestataire si vous le souhaitez.
Bien sûr. Le code est documenté, la stack est standard (PHP/MySQL/JS vanilla ou frameworks reconnus), et un dossier de transmission est livré avec chaque projet. Aucun engagement de maintenance, vous décidez à tout moment.
30% d'acompte à la signature, 70% à la livraison. Paiement sécurisé via Stripe (CB, Apple Pay, virement SEPA) ou virement bancaire classique. Échelonnement en 3x sans frais possible sur les projets > 2 000 € HT.
On recommande OVH (France, RGPD-compatible) pour la majorité des projets. Pour des besoins spécifiques (haute dispo, scalabilité), on peut déployer sur AWS, Scaleway ou Cloudflare Pages. C'est analysé au cadrage.
